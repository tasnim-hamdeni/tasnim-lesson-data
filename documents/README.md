# Public lesson documents

Tasnim's PDF and PPTX uploads are stored in subject folders here, using unique lesson identifiers as file names. The public catalog at `../catalog.json` records their titles, subjects, types, sizes, and dates.

This library currently contains no lesson documents. Add real lessons through the teacher administration page after connecting with a fine-grained token scoped only to this data repository.

All documents are public. Never upload private student information. Removing a lesson does not erase previously published copies from Git history or other devices.
